# 09 - 证据与参考资料

> **文档状态**：Draft 0.4  
> **上级文档**：[00-项目管理服务设计文档索引](./00-项目管理服务设计文档.md)

---

以下资料用于支撑技术选型相关事实；它们不替代针对 Projecty 实际流量、权限和部署环境的 PoC。

- **[E1][强证据｜官方文档] Axum Documentation**：`axum::Router`、handler、extractor、typed `State`；支撑 Axum 路由组合、请求提取和共享应用状态的设计。  
  https://docs.rs/axum/latest/axum/

- **[E2][强证据｜官方文档] SeaORM Documentation**：Migration、schema-first、entity generation、relations、pagination；支撑数据库迁移先行和实体同步的设计。  
  https://www.sea-ql.org/SeaORM/docs/

- **[E3][强证据｜官方文档] SeaORM Transaction**：closure transaction、begin/commit、nested transaction、PostgreSQL isolation；支撑任务拖拽、编号和审计的事务边界。  
  https://www.sea-ql.org/SeaORM/docs/advanced-query/transaction/

- **[E4][强证据｜官方文档] SvelteKit Documentation**：Routing、Layouts、Loading data、Form actions、Server routes；支撑多路由复杂 Web 前端而非单一页面容器的设计。  
  https://svelte.dev/docs/kit

- **[E5][强证据｜官方文档] PostgreSQL Documentation - Constraints**：check、not-null、unique、primary key、foreign key；支撑数据库约束作为数据完整性兜底。  
  https://www.postgresql.org/docs/current/ddl-constraints.html

- **[E6][强证据｜官方文档] PostgreSQL Documentation - Row Security Policies**：按命令/角色配置行安全、默认拒绝、owner/superuser/BYPASSRLS 行为；支撑 RLS 仅作为经过验证的防御层，而不是未经 PoC 的唯一授权方案。  
  https://www.postgresql.org/docs/current/ddl-rowsecurity.html

- **[E7][强证据｜官方文档] PostgreSQL Documentation - Transaction Isolation**：Read Committed、Repeatable Read、Serializable；支撑并发写入 PoC 和隔离级别选择需要结合实际业务验证。  
  https://www.postgresql.org/docs/current/transaction-iso.html
